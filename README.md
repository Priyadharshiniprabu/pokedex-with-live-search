# Pokédex with Live Search

A React-based Pokédex application that allows users to browse and search for Pokémon using a live search feature.

## About the Project

This project provides a simple and interactive way to explore Pokémon. The live search functionality allows users to quickly find Pokémon by entering their name.

## Features

- Browse Pokémon
- Live search functionality
- Search Pokémon by name
- Display Pokémon information
- Responsive and user-friendly interface
- Fast and dynamic search results

## Technologies Used

- React.js
- JavaScript
- HTML5
- CSS3
- REST API

## Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/nandhini-80/pokedex-with-live-search.git
```

### 2. Navigate to the Project

```bash
cd pokedex-with-live-search
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Run the Application

```bash
npm start
```

The application will run in development mode.

Open:

`http://localhost:3000`

in your browser.

## Available Scripts

### `npm start`

Starts the application in development mode.

### `npm test`

Runs the test runner in interactive watch mode.

### `npm run build`

Creates an optimized production build inside the `build` directory.

## Project Purpose

The purpose of this project is to practice React development, API integration, state management, and dynamic search functionality.
